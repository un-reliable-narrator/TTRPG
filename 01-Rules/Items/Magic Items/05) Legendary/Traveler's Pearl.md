# Traveler's Pearl

[Home](http://dnd2024.wikidot.com/home:home) » [Magic Items](http://dnd2024.wikidot.com/magic-item:all) » Traveler's Pearl

Source: Arcana Unleashed

_Wondrous Item, Legendary (Requires Attunement)_

By using a command word while holding this pearl, you can cast the [Teleport](http://dnd2024.wikidot.com/spell:teleport) spell from it. Once this property is used, it can’t be used again until the next dawn.
