# Actions
*Source: Player's Handbook (2024) p. 15. Available in the <span title='Systems Reference Document (5.2)'>SRD</span> and the Free Rules (2024)* 

**Actions**

| Action                    | Summary                                                                                                                                                                                                                                                                                                                     |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [[Attack]]                | Attack with a weapon or an [Unarmed Strike](Unarmed%20Strike.md).                                                                                                                                                                                                                                                             |
| [Dash](Dash.md)           | For the rest of the turn, give yourself extra movement equal to your [Speed](01-Rules/Rules/Speed.md).                                                                                                                                                                                                           |
| [Disengage](Disengage.md) | Your movement doesn't provoke [[Opportunity Attacks]] for the rest of the turn.                                                                                                                                                                                                                                             |
| [Dodge](Dodge.md)         | Until the start of your next turn, attack rolls against you have [[01-Rules/Rules/variant-rules/Disadvantage\|Disadvantage]], and you make Dexterity saving throws with [[Resources/Backlinks/Rules/Advantage|Advantage]]. You lose this benefit if you have the [Incapacitated](Conditions.md#Incapacitated) condition or if your Speed is 0. |
| [Help](Help.md)           | Help another creature's ability check or attack roll, or administer first aid.                                                                                                                                                                                                                                              |
| [Hide](Hide.md)           | Make a Dexterity ([Stealth](Stealth.md)) check.                                                                                                                                                                                                                                                                             |
| [Influence](Influence.md) | Make a Charisma ([Deception](Deception.md), [[Intimidation]], [Performance](Performance.md), or [[Persuasion]]) or Wisdom ([Animal Handling](Animal%20Handling.md)) check to alter a creature's attitude.                                                                                                                   |
| [Magic](Magic.md)         | Cast a spell, use a magic item, or use a magical feature.                                                                                                                                                                                                                                                                   |
| [Ready](Ready.md)         | Prepare to take an action in response to a trigger you define.                                                                                                                                                                                                                                                              |
| [Search](Search.md)       | Make a Wisdom ([[Insight]], [Medicine](Medicine.md), [[Perception]], or [[Survival]]) check.                                                                                                                                                                                                                                |
| [Study](Study.md)         | Make an Intelligence ([[Arcana]], [[History]], [[Investigation]], [[Nature]], or [Religion](Religion.md)) check.                                                                                                                                                                                                            |
| [Utilize](Utilize.md)     | Use a nonmagical object.                                                                                                                                                                                                                                                                                                    |
