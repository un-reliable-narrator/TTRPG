# Magic Item Tools
*Source: Dungeon Master's Guide (2024) p. 220* 

**Magic Item Tools**

| Item Category | Required Tool |
|---------------|---------------|
| Armor | [Leatherworker's Tools](leatherworkers-tools.md), [Smith's Tools](Smiths-Tools.md), or [Weaver's Tools](weavers-tools.md) depending on the kind of armor as noted in the tools' descriptions |
| Potion | [Alchemist's Supplies](Alchemists-Supplies.md) or [Herbalism Kit](herbalism-kit.md) |
| Ring | [Jeweler's Tools](jewelers-tools.md) |
| Rod | [Woodcarver's Tools](woodcarvers-tools.md) |
| Scroll | [Calligrapher's Supplies](Calligrapher's%20Supplies.md) |
| Staff | [Woodcarver's Tools](woodcarvers-tools.md) |
| Wand | [Woodcarver's Tools](woodcarvers-tools.md) |
| Weapon | [Leatherworker's Tools](leatherworkers-tools.md), [Smith's Tools](Smiths-Tools.md), or [Woodcarver's Tools](woodcarvers-tools.md) depending on the kind of weapon as noted in the tools' descriptions |
| Wondrous Item | [Tinker's Tools](Tinkers-Tools.md) or the tool required to make the nonmagical item on which the magic item is based |
^magic-item-tools

**Arcana Proficiency** To craft a magic item, you and any assistants must have proficiency in the Arcana skill.

**Tools** The Magic Item [Tools](magic-item-tools.md) table lists which tool is required to make a magic item of each category. You must use the required tool to make an item and have proficiency with that tool. Any assistants must also have proficiency with it.

**Spells** If a magic item allows its user to cast any spells from it, you must have all those spells prepared every day you spend crafting the item.

**Time and Cost** Crafting a magic item takes an amount of time and money based on the item’s rarity as shown in the Magic Item Crafting [Time and Cost](magic-item-crafting-time-and-cost.md) table.

**Work per Day.** For each day of crafting, you must work for 8 hours. If an item requires multiple days, those days needn’t be consecutive.

**Assistants.** Characters can combine their efforts to shorten the crafting time. Divide the time needed to create an item by the number of characters working on it. Normally, only one other character can assist you, but the DM might allow more assistants.

**Raw Materials.** The cost in the table represents the raw materials needed to make a magic item. The DM determines whether appropriate raw materials are available. In a city, there is a 75 percent chance that the materials are available, and in any other settlement, that chance is 25 percent. If materials aren’t available, you must wait at least 7 days before checking on the availability again.

If a magic item incorporates an item that has a purchase cost (such as a weapon or a suit of armor), you must also pay that entire cost or craft that item using the rules in the Player’s Handbook. For example, to make [+1 Armor (Plate Armor)](http://dnd2024.wikidot.com/magic-item:armor-1-2-or-3), you must pay 3,500 GP or pay 2,000 GP and craft the armor.
