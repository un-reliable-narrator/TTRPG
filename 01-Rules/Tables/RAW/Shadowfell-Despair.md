# Shadowfell Despair
*Source: Dungeon Master's Guide (2024) p. 209* 

**Shadowfell Despair**

| dice: 1d6 | Effect                                                                                                                                                                    |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1–3       | Apathy. The character has [[01-Rules/Rules/Disadvantage\|Disadvantage]] on [Death Saving Throws](death-saving-throw.md) and [Initiative](01-Rules/Rules/Initiative.md) rolls. |
| 4–5       | Dread. The character has [[01-Rules/Rules/Disadvantage\|Disadvantage]] on all saving throws.                                                                                             |
| 6         | Delusion. The character has [[01-Rules/Rules/Disadvantage\|Disadvantage]] on ability checks and saving throws that use Intelligence, Wisdom, or Charisma.                                |
