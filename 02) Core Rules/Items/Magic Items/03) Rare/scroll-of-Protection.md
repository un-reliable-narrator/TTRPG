# Scroll of Protection
*Scroll, rare*  
![](items/XDMG/Scroll of Protection.webp#right)


Each Scroll of Protection works against creatures of a specific creature type chosen by the DM or determined by rolling on the following table.

| dice: 1d100 | Creature Type |
|-------------|---------------|
| 01-10 | [Aberrations](scroll-of-Protection-Aberrations.md) |
| 11-15 | [Beasts](scroll-of-Protection-Beasts.md) |
| 16-20 | [Celestials](scroll-of-Protection-Celestials.md) |
| 21-25 | [Constructs](scroll-of-Protection-Constructs.md) |
| 26-35 | [Dragons](scroll-of-Protection-dragons.md) |
| 36-45 | [Elementals](scroll-of-Protection-elementals.md) |
| 46-50 | [Humanoids](scroll-of-Protection-humanoids.md) |
| 51-60 | [Fey](scroll-of-Protection-fey.md) |
| 61-70 | [Fiends](scroll-of-Protection-fiends.md) |
| 71-75 | [Giants](scroll-of-Protection-Giants.md) |
| 76-80 | [Monstrosities](scroll-of-Protection-monstrosities.md) |
| 81-85 | [Oozes](scroll-of-Protection-oozes.md) |
| 86-90 | [Plants](scroll-of-Protection-Plants.md) |
| 91-00 | [Undead](scroll-of-Protection-Undead.md) |
^1-creature-type

Using a [Magic](Magic.md) action to read the scroll creates a 5-foot Emanation originating from you. For 5 minutes, creatures of the specified type can't enter or affect anything in the area. However, if you move in such a way that a creature of the specified type would be inside the area, the effect ends.

As a [Magic](Magic.md) action, a creature within 5 feet of the Emanation can attempt to overcome it, which forces the creature to make a DC 15 Charisma saving throw. On a successful save, the creature ceases to be affected by the Emanation.
