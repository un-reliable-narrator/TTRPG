# Attitude
*Source: Player's Handbook (2024) p. 361. Available in the <span title='Systems Reference Document (5.2)'>SRD</span> and the Free Rules (2024)* 

A [monster](monster.md) has a starting attitude toward a [player character](player-character.md): [Friendly](friendly-attitude.md), [Hostile](hostile-attitude.md), or [Indifferent](indifferent-attitude.md).
