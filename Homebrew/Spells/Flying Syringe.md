# Flying Syringe
*Level 1 ??? (Artificer)*

**Casting Time:​** Action
**Range:** 60 ft.
**Components:** S, M (a Syringe)
**Duration:** Instantaneous

You toss a Syringe. *Ranged ~~Weapon~~ Spell Attack:* One target, range 30/120 ft. *Hit:* 1 piercing damage and the target is poisoned for 1 minute. While poisoned, it suffers an additional effect (roll on the table below).

| 1d6 | Effect                                                                                                                                                                                             |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **Harm.** The target loses 2d8 hit points. (If the target is alive when it loses the poisoned condition, it may regain these hit points.)                                                          |
| 2   | **Slow.** Target's speed is reduced by 10 ft.                                                                                                                                                      |
| 3   | **Frail.** Attacks against the target have advantage                                                                                                                                               |
| 4   | **Timid.** Roll 1d4 and subtract the number rolled from saving throw the target makes.                                                                                                             |
| 5​  | **Heavy.** Target drops prone. Standing up requires the target to make a Strength save (DC equals your spell save DC). *Failure:* Target remains prone and loses all remaining movement this turn. |
| 6   | Choose two effects from the other rows in this table.                                                                                                                                              |
