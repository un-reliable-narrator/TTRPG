# Edits to Strahd's Statblock

### Actions
*+Added Spells*
- At Will: [[Prestidigitation]], [[Ray-of-Frost]]

***Protective Magic (2/Day).*** The mage casts [Counterspell](app://obsidian.md/counterspell) in response to the spell's trigger, using the same spellcasting ability as Spellcasting.
